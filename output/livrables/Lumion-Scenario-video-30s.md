# Lumion - Vidéo de présentation (30 secondes)

Auteur : PETNOU HONLUE FREDERIC ARMEL
Matricule : 22G00362
Filière : GÉNIE INFORMATIQUE (GÉNIE LOGICIEL)

## Format de remise

Vidéo MP4 de 30 secondes, avec ta vraie voix et ton visage visible en incrustation pendant la démonstration. Enregistrer l'écran de l'application avec une webcam et un microphone ; conserver le visage dans un coin qui ne masque pas les boutons. Un écran d'application seul ne satisfait pas l'exigence « voix + visage ».

## Texte à prononcer

« Bonjour, je suis Petnou Honlue Frédéric Armel. Voici Lumion, une application de signalement des coupures d'électricité à Douala. La carte présente l'état des quartiers. Ici, je signale une coupure ; les confirmations des habitants permettent de la valider. L'historique et les statistiques facilitent le suivi. Un mode autonome permet aussi la démonstration sans serveur. Lumion est développé avec .NET MAUI et ASP.NET Core. Merci. »

Le texte compte environ 70 mots. Répéter au chronomètre, puis ajuster le débit pour tenir exactement 30 secondes.

## Déroulé à préparer

| Temps | Image / action |
|---|---|
| 00-05 s | Visage visible et accueil de Lumion ; présentation personnelle. |
| 05-10 s | Montrer la carte et sélectionner un quartier. |
| 10-18 s | Ouvrir le formulaire, envoyer un signalement préparé et montrer le résultat. |
| 18-25 s | Montrer l'historique ou les statistiques, puis mentionner le mode autonome. |
| 25-30 s | Garder une vue claire de l'application ; annoncer les technologies et remercier. |

## Avant la prise

- Utiliser des données de démonstration et se connecter avant l'enregistrement.
- Préparer les écrans pour éviter de saisir un code OTP pendant les 30 secondes.
- Si le serveur local est utilisé, démarrer Lumion.Api et Lumion en Debug avant la prise.
- Si le réseau pose problème, choisir Profil > Connexion > Mode autonome. Attention : ce mode rend les données métier locales, mais ne télécharge pas le fond OpenStreetMap sans Internet. Vérifier le rendu de la carte avant de filmer.
- Tester le microphone et la webcam ; couper les notifications personnelles.
- Faire une répétition complète. Ne pas prétendre montrer une confirmation si le seuil n'a pas été atteint.
- Relire la vidéo finale : visage visible, voix audible, texte lisible, durée de 30 secondes.
